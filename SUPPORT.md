# Getting help

- **How do I…?** Start with the [user guide](USER-GUIDE.md), or the built-in **Guide** and **Help
  assistant** in the app. There's also the [CaseKeeper wiki](https://darkciphersystems.com/wiki-casekeeper.html).
- **Something isn't working:** open a [bug report](../../issues/new/choose), or use
  <https://darkciphersystems.com/support.html>.
- **An idea:** open a [feature request](../../issues/new/choose).
- **A security problem:** please report it privately, as described in [SECURITY.md](SECURITY.md).

> **Never post case documents, names, dates of birth, case numbers or other personal details in
> an issue.** Issues may become public. Describe the problem and include the *Reference* code from
> the error message instead: it points to the log entry without revealing anything.

CaseKeeper is an organising tool. Nobody here can give legal advice. For that, try a solicitor,
Citizens Advice, a law centre or an advice service such as [Advicenow](https://www.advicenow.org.uk).
